# Сохранение изменений в Git

После выполнения и проверки каждой правки в этом проекте создай коммит с относящимися к задаче изменениями и отправь его в настроенную upstream-ветку. Если пользователь просит оставить изменения локально, соблюдай это указание. Запросы на чтение и диагностику без изменений файлов не требуют коммита.

Перед коммитом проверь его состав. Учитывай уже подготовленные изменения пользователя. Храни `.env`, ключи, локальные базы, дампы и логи вне новых коммитов. Если отправка завершилась ошибкой, сообщи хеш локального коммита и причину сбоя.

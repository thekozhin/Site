# Обновление CSRF для всех страниц — 19.11.2026

Общая base.html подключает static/js/csrf-refresh.js. Перед изменяющим запросом своей страницы клиент получает свежую подпись CSRF через GET /csrf-token. Одновременные запросы используют одно обновление; свежая подпись повторно используется до 30 секунд. После возврата на вкладку подпись проверяется заново перед следующим действием. Фоновых таймеров нет.

Обновляются мета-тег, скрытые поля форм, X-CSRFToken и существующее поле csrf_token в передаваемой FormData/URLSearchParams. Это важно: Flask-WTF сначала проверяет поле формы и только затем заголовок. Старое поле нельзя оставлять вместе со свежим заголовком.

Покрыты обычная отправка форм (с сохранением нажатой кнопки), программный form.submit(), fetch и асинхронный XMLHttpRequest. Данные других полей не меняются. Сторонние домены и обычные GET не получают CSRF-токен. Уже отправленные POST не повторяются автоматически. Если обновление не удалось, действие останавливается до отправки, введённые данные сохраняются, показывается сообщение.

`/csrf-token` доступен до входа для долгоживущей формы авторизации. Он подписывает только токен текущей браузерной сессии, не авторизует пользователя и не меняет права. Ответ помечен no-store, private и Vary: Cookie. Старый /index/csrf-token продолжает требовать вход и совместим с обновлением списка заявок. Срок проверки CSRF не увеличен и защита не отключена.

Контроллеры закрытия перед финальным обычным POST также ожидают обновления, чтобы сетевой сбой не оставил форму с заблокированными кнопками. Правила проверки и подписания InControl не менялись.

Проверено: 83 серверных теста, 11 клиентских проверок Node, браузерная отправка обычной формы и AJAX с подписью старше двух часов в изолированной среде без MySQL/InControl. Рабочие заявки во время проверки не менялись.

Для обновления заменить app.py, templates/base.html, templates/complete_task.html, static/js/completion-check.js, static/js/incontrol-inline.js; добавить static/js/csrf-refresh.js. Перезапустить приложение и один раз обновить открытые страницы. SQL и изменение .env не требуются.

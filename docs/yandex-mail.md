# Заявки из Яндекс Почты

Пилот читает «Входящие» и сверяет борт из темы со справочником 14-го парка. Для импорта нужны заявка без ответа и вложение `.xls` или `.xlsx` с тем же номером борта. Ответ отправляется в исходную переписку.

## Настройка на сервере

1. Включите IMAP и «Пароли приложений и OAuth-токены» в настройках Яндекс Почты. Включите для IMAP папку «Входящие». Выберите вход через OAuth или с паролем приложения типа «Почта». [Настройки IMAP и SMTP](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)
2. В MySQL выполните `docs/migrations/2026-11-20-yandex-mail.sql`. Из окружения приложения можно вместо SQL вызвать `python -m flask --app app init-yandex-mail`.
3. Укажите параметры в `.env` на сервере.

   ```dotenv
   YANDEX_MAIL_ADDRESS=SetransUZ@yandex.ru
   YANDEX_MAIL_APP_PASSWORD=
   YANDEX_MAIL_FOLDERS='{"14 парк":"INBOX"}'
   YANDEX_MAIL_IMPORT_FROM=2026-11-21T20:36:03
   YANDEX_MAIL_ENABLED=0
   ```

4. Заполните `YANDEX_MAIL_APP_PASSWORD` или настройте OAuth по инструкции ниже. Запустите просмотр `RUN_SCHEDULER=0 python -m flask --app app yandex-mail-sync`. Команда выведет заявки без записи в базу, отправки писем и изменения статуса прочтения. Для разового импорта добавьте `--apply`.
5. Установите `YANDEX_MAIL_ENABLED=1` и перезапустите экземпляр приложения с `RUN_SCHEDULER=1`. Минуты запуска задаёт `CronTrigger` задания `yandex_mail_sync` в `app.py`. При `minute='*/1'` обход выполняется каждую минуту. Если папка отправленных не обнаружена, задайте её имя через `YANDEX_MAIL_SENT_FOLDER`.

`YANDEX_MAIL_IMPORT_FROM` задаёт дату и время получения письма для импорта новых заявок по Москве включительно. Формат `ГГГГ-ММ-ДДTЧЧ:ММ:СС`. Если указана только дата, отсчёт идёт с полуночи. Пустое значение включает все даты. Поиск письма для ответа при закрытии использует собственный период, указанный ниже. После изменения `.env` перезапустите приложение.

`YANDEX_MAIL_FOLDERS` определяет парки и для импорта, и для автоматической отправки ответов. Для другого парка добавьте его точное название из Сетранс и отдельную папку IMAP. Для автоматической отписки в InControl добавьте название в `INCONTROL_CLOSURE_PARKS` через запятую. Пример для 14-го и 1-го парков.

```dotenv
YANDEX_MAIL_FOLDERS='{"14 парк":"INBOX","1 парк":"1АП NEW"}'
INCONTROL_CLOSURE_PARKS='14 парк,1 парк'
```

## Вход через OAuth

Яндекс Почта поддерживает OAuth для IMAP и SMTP. Зарегистрируйте приложение для доступа к API. Выберите `mail:imap_full` для чтения, отметки об ответе и сохранения отправленного письма, а также `mail:smtp` для отправки. [Регистрация приложения](https://yandex.ru/dev/id/doc/ru/register-api) · [Права Яндекс Почты](https://yandex.ru/support/yandex-360/business/mail/ru/web/security/oauth.html)

1. В терминале проекта запустите `RUN_SCHEDULER=0 python -m flask --app app yandex-mail-authorize`. Введите Client ID и Client Secret из карточки приложения. Ввод Client Secret скрыт.
2. Откройте ссылку из терминала, выберите аккаунт `YANDEX_MAIL_ADDRESS`, введите показанный код и подтвердите доступ. Команда сверит владельца токена через Яндекс ID, проверит вход по IMAP и сохранит токены в `~/.config/setrans/yandex-mail-oauth.json` с правами `600`. Другой путь задаётся через `YANDEX_MAIL_OAUTH_FILE`. Храните файл вне публичного каталога сайта.
3. Проверьте доступ и выбор источника командой `RUN_SCHEDULER=0 YANDEX_MAIL_AUTH=oauth python -m flask --app app yandex-mail-sync`. Для включения синхронизации через OAuth задайте `YANDEX_MAIL_AUTH=oauth` в `.env` и перезапустите приложение. Токен обновляется автоматически. [Обновление токена Яндекс OAuth](https://yandex.ru/dev/id/doc/ru/tokens/refresh-client)

## Журнал

В `logs/app.log` строка `Яндекс Почта | 14 парк | Добавлены борта …` показывает парк и борта новых заявок. Ошибки подключения и синхронизации записываются отдельно.

## Закрытие заявки

При закрытии ручной заявки без привязанного письма Сетранс ищет по точному номеру борта в теме. Проверяется последнее письмо без ответа, полученное к моменту закрытия. У письма должно быть корректное вложение заявки. Письмо, уже связанное с другой заявкой, остаётся в её переписке. Для обновления выполните [SQL для очереди поиска по теме](migrations/2026-11-22-yandex-reply-lookup.sql) и загрузите `app.py`, `yandex_mail.py` и `yandex_requests.py`.

Для планового ТО Сетранс также читает значение «Вид ремонта» во вложении и сверяет борт, парк и вид ТО. Учитываются письма начиная за 24 часа до создания заявки ТО и по момент её закрытия. Импорт привязывает письмо к подходящему плановому ТО в работе. При закрытии без привязки Сетранс находит последнее подходящее письмо без ответа и отправляет текст выполненных работ. Для чтения старого формата `.xls` обновите зависимости командой `python -m pip install -r requirements.txt`.

Номер из шапки Excel определяет заявку внутри парка. Идентификатор исходного письма определяет переписку. При повторном импорте база проверяет оба идентификатора по индексам. Письма с флагом ответа или с ответом в папке отправленных пропускаются.

Письмо с новым номером заявки Excel привязывается к ремонту в работе, если совпадают борт, парк и адрес для ответа. В теме должен однозначно определяться номер борта. Подойдут «162828», «162828 Новое» и «162828 ДОПОЛНЕНИЕ». В карточке остаётся описание из самого свежего письма. При закрытии одинаковый текст выполненных работ отправляется отдельным ответом на каждое письмо, оставшееся без ответа. Перед обновлением выполните [миграцию для дополнений](migrations/2026-11-23-yandex-supplements.sql).

Для ремонта Яндекс Почта и InControl создают заявку, когда по борту нет записи в работе. Если по тому же борту и парку есть подходящая ручная заявка, импорт добавляет к ней внешнюю привязку и новые строки описания. Номер, автор и время создания сохраняются. При других совпадениях очередной импорт проверит внешнюю заявку после завершения текущей.

Если по борту есть открытые заявки InControl, приёмщик с личным подключением выбирает соответствующую заявку. Если письмо относится к отдельному ремонту, он может явно выбрать это в форме. Действующая проверка InControl без личного подключения используется и для заявок из почты.

При сохранении закрытия Сетранс в той же транзакции кладёт `completed_work` в очередь. Сразу после сохранения фоновая задача проверяет наличие ответа на конкретное письмо и отправляет этот текст в исходную переписку. Планировщик проверяет очередь каждую минуту отдельно от импорта. При временном отказе SMTP попытки повторяются через 1, 5 и затем каждые 15 минут.

После подтверждения SMTP Сетранс сохраняет копию в «Отправленных», если её ещё нет, и ставит на исходное письмо флаги «Отвечено» и «Важное». При сбое IMAP повторяется незавершённый шаг. Если подтверждение SMTP потерялось, Сетранс проверяет «Отправленные» по `Message-ID` и исходную переписку. После трёх проверок без подтверждения заявка попадает в «К отписке» своего парка. Явный постоянный отказ SMTP сразу попадает в этот список. Для проверки состояния очереди используйте `python -m flask --app app yandex-mail-status`.

Перед обновлением выполните [SQL для повторов почтовой отписки](migrations/2026-11-23-yandex-reply-retry.sql). Затем обновите `app.py`, `yandex_mail.py`, `yandex_requests.py`, `incontrol_outbox.py` и `templates/incontrol_pending.html` и перезапустите приложение с включённым планировщиком.

## Пауза при закрытии

В настройках под шестерёнкой можно отдельно приостановить проверку InControl и отправку ответа в Яндекс Почте до выхода из аккаунта. При закрытии в паузе отложенные отписки попадают в «К отписке» выбранного парка. Для двух сервисов создаются две записи с отдельными отметками. Сохранённые в списке ответы отправляются вручную из почты.

Перед обновлением существующей таблицы выполните [SQL для общего списка](migrations/2026-11-21-shared-pending-closures.sql). Затем обновите файлы и перезапустите приложение.

- `app.py`, `completion_checks.py`, `incontrol_accounts.py`, `incontrol_outbox.py`, `incontrol_rejection_jobs.py`, `yandex_requests.py`
- `templates/base.html`, `templates/complete_task.html`, `templates/incontrol_pending.html`, `templates/incontrol_settings.html`
- `static/js/incontrol-pending.js`
